# Contributing to Firebase Rules Learning Assistant

Thank you for your interest in contributing to the Firebase Rules Learning Assistant! This document provides guidelines and instructions for contributing to this project.

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all your interactions with the project.

## Getting Started

1. **Fork the Repository**
   - Click the "Fork" button on the GitHub repository page
   - Clone your fork: `git clone https://github.com/David-Pena/firebase-rules-learning-assistant.git`
   - Navigate to the project directory: `cd firebase-rules-learning-assistant`

2. **Install Dependencies**
   ```bash
   pnpm install
   ```

3. **Run desired environment / project**
   - `pnpm docs:dev` to run the documentation website
   - `pnpm app:dev` to run the learning assistant

## Development Workflow

1. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/your-bug-fix
   ```

2. **Commit Changes**
   - Use conventional commits format:
     ```
     feat: add new feature
     fix: resolve bug
     docs: update documentation
     style: format code
     refactor: restructure code
     test: add tests
     chore: update dependencies
     ```
   - Keep commits focused and atomic
   - Write clear commit messages

4. **Push Changes**
   ```bash
   git push origin your-branch-name
   ```

5. **Create Pull Request**
   - Fill in the PR template
   - Submit the PR

Thank you for contributing to Firebase Rules Learning Assistant!
